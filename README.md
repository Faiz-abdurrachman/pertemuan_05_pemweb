# Starter Kit — Praktikum Pemrograman Web (Pertemuan 05)
## Routing Dinamis, HTTP Methods (GET & POST), dan Formulir Interaktif

Starter kit sederhana berbasis Flask dan Jinja2 untuk mahasiswa praktikum Pemrograman Web 2026.

---

### Cara Menjalankan Proyek:

1. **Clone repositori**:
   ```bash
   git clone https://github.com/Faiz-abdurrachman/pertemuan_05_pemweb.git praktikum-p05
   cd praktikum-p05
   ```

2. **Buat & aktifkan virtual environment**:
   - **Windows (CMD / PowerShell)**:
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```
   - **macOS / Linux**:
     ```bash
     python3 -m venv .venv
     source .venv/bin/activate
     ```

3. **Install Flask**:
   ```bash
   pip install flask
   ```

4. **Jalankan server**:
   ```bash
   python app.py
   ```
   Buka peramban di: `http://127.0.0.1:5000`
